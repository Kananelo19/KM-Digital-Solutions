# Client Projects

KM Digital Solutions is the business/studio website. Client websites should be built as separate deliverables so each business can have its own domain, launch checklist, assets, and clean source code.

## Workflow

1. Create a private preview from the client's business type and services.
2. Confirm scope, pages, content, price, and deposit.
3. Build the client website in its own folder or repository.
4. Test mobile, forms, calls-to-action, SEO basics, and launch details.
5. Launch on the client's domain and add the result back to the KM Digital portfolio.
